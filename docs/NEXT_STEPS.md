## Not built

These are the same open items as the README. None of them is a result.

- A language-agent research assistant on this terminal. It would call the local API, cite the cached source behind each number, and refuse a figure those responses do not contain.
- Release-vintage World Bank series, so a forecast can be checked at publication time. The current rows are revised history.
- More than one held-out network year. Three training years and one test year are a feasibility check. Ridge has the lowest test RMSE on that year.
- Firefox, Safari, and a human accessibility pass. The automated UI suite is Chromium.

## Research still required

Further research needs more temporal network observations and release-vintage-aware outcomes; independent chronological tests; identified causal mechanisms before mapping an event into macro or market effects; licensed total-return datasets and predeclared multiple stress scenarios before robust portfolio claims. More model complexity is not a substitute for data or evidence.

## Product still required

Broader release needs comprehensive licensed world-news coverage, human beginner-comprehension and accessibility testing, and clean cross-platform browser installation tests. An internet-facing service needs an explicit deployment design, authentication, a security review, and operating monitoring. The loopback app does not include those.
